# Rusty Rival v1.0.76

An exact-search speed improvement: main search reuses one move-list buffer for staged captures, quiet moves and check evasions. Generation writes into that buffer; filtering, scoring, selection order and search decisions stay unchanged. The network, evaluation scale and search parameters are unchanged.

## Performance evidence

Two fresh matched PGO rebuild pairs on one Ryzen 9 5950X host, Linux x86-64-v3, one thread and Hash 128 MB:

| Pair | Benchmark depth 20 | Held-out 60 positions, depth 16 |
| --- | --- | --- |
| 1 | +1.43% [1.17%, 1.69%] | +1.24% [0.50%, 1.98%] |
| 2 | +1.37% [0.68%, 2.08%] | +1.66% [0.73%, 2.60%] |

Intervals are 95% log-t intervals over four timing blocks within each build pair. Pairs are reported separately, not pooled. All 16 candidate timing blocks were positive. Same-source rebuild controls were -0.02% on the benchmark and -0.07% on held-out positions, with both intervals spanning zero; results are not adjusted by these controls.

A separate depth-18 diagnostic on pair 2 measured +1.62% [1.21%, 2.03%], with 85,335,711 identical nodes across 60 positions. This is a diagnostic, not a third independent pair.

## Correctness and scope

- Each PGO pair passed 80 fixed-node and 60 held-out fixed-depth identities, including score, best move, principal variation and node count. The 80 positions are also PGO training positions.
- Full release workspace: 293 passed, zero failed or filtered, three existing ignored tests. Debug library and all three pool integration suites passed, as did Clippy and 17 Python tests.
- Portable x86-64-v2 baseline/candidate and portable/AVX2 cross-kernel comparisons each passed 140 identities on this host.
- No claim of Elo gain, universal CPU speedup, or measured performance on Windows, macOS or ARM. The other platform builds require release CI; portable checks establish identity, not speed.
- The release contains only the confirmed pool change. Other research variants and small unconfirmed gains are excluded.

Versioned packaging and public-asset execution verification are required before the Lichess bot upgrade. Existing settings, opening book and Syzygy files are preserved.
