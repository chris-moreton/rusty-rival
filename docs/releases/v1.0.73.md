# Rusty Rival 1.0.73

This release reduces search overhead while preserving fixed-work search results. The NNUE network, evaluation scale, search parameters, tablebase behavior and UCI settings are unchanged from v1.0.72.

## Changes

- Borrow NNUE piece snapshots instead of copying them during lazy accumulator updates.
- Skip quiescence static exchange evaluation when a non-negative result is provable, retaining promotion-rank safeguards.
- Gather changed NNUE features in one pass while preserving list order and fallback behavior.
- Reduce move-picker keys through four independent lanes with the same tie ordering.

## Validation and measured performance

Two fresh matched x86-64-v3 PGO build pairs on a Ryzen 9 5950X measured benchmark NPS gains of 2.12% and 1.92%, and held-out gains of 1.37% and 1.54%. A deeper-search diagnostic measured 1.51%. These are single-thread measurements on one host, not an Elo claim or a promise of equal gains on other CPUs/platforms.

Both research build pairs matched all 80 fixed-node and 60 fixed-depth identity positions, including nodes, scores, principal variations and best moves. The research candidate passed 277 release tests with no exclusions, plus formatting, clippy and Python checks. Versioned and public-artifact verification is recorded separately during release packaging.

The unchanged-source PGO rebuild control was benchmark-only; there was no held-out rebuild control. The two candidate pairs are reported separately, not pooled as independent machines.

All platforms retain the existing release build routes. Linux AVX2 uses a fresh PGO profile; older x86 CPUs should use the portable x86-64 asset. No PEXT-specific requirement was added.
