# NET-1445: v1.0.70 evaluation update

## Engine change

Compared with v1.0.69, replace the embedded 512-wide, eight-bucket NNUE network
and set its runtime output scale to 575. Architecture, inference arithmetic,
search parameters and replacement logic are unchanged. The weight file retains
its historical `rival-512x2-ob8-corrected-net1095.bin` filename; it now contains
the NET-1445 network.

Network SHA-256: `efb2a47d2aece73939066679f0445ea3d542ed36faff6a9b4134b62aa50e743c`.
Training: bullet c1a3433, seed 198273616, 600 superbatches of 6104 batches of
16384 positions (60,004,761,600 presentations), full 512,363,260-record
Stockfish depth-9 corpus. The target uses 25% game result and 75% sigmoid teacher
score, with training scale 400. Historical blanket result correction, one-time
frozen shuffle and quantisation/export contract are retained. GPU training is
not bit-reproducible. Final checkpoint only; no seed/checkpoint selection.

Runtime scale 575 was selected before scaled games by the frozen static
least-squares calibration against net1095 (factor 1.4378419191). A separate
3200-game same-net scale575-versus400 study passed; that is not the production
comparison below and its Elo must not be added to it.

## Regression and known limitations

Six suites at 300k nodes, candidate/public solved: Arasan 75/62, BK 18/20,
EET 39/46, quick 6/7, STS 997/973, WAC 276/274. These mixed diagnostics were
preserved; improved match strength does not imply every position improved.

The root fallback fixture retains its behavior assertions. Node/depth budgets
were calibrated to the new net's search trajectory; the scale575 retained
fail-high interval was measured before choosing its 1,235,000-node midpoint.
Synthetic NNUE expectations scale with 575; the symmetry test includes an exact
colour/vertical mirror check.

The eight pinned golden outputs are 75, -109, 105, -9, 765, 537, 104, -10 cp
for the existing test FENs. They were calculated independently from quantised
weights using Chess768 perspective features, integer accumulators, activation
`clamp(x,0,255)^2 / 255`, bucket-major L1 and truncation toward zero of
`total * 575 / 16320`. Both mover perspectives are covered. Engine agreement is
required by the release's unfiltered full test suite. Raw bare-kings output is
104 cp; search adjudicates insufficient material before using it.

The final versioned release build must preserve fixed-node identity against the
qualified PGO candidate; packaging evidence records that separately. No change
to production deployment is implied by this document.
